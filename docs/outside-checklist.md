# Outside proof - 15 min, do this yourself (agent cannot go outside)

Judges give bonus points for real use. A faked photo = invalid submission, so do this for real:

1. Phone: open your Render URL (or `http://your-laptop:8000` on same WiFi). Tap Use my location, 20 min, your needs. Screenshot results.
2. Walk to pocket #1. Photo 1: bench/path + your phone showing the mission card. Photo 2: you sitting in the sun (ask a passerby or selfie).
3. Video 90s (phone, one take): 0-20s screen search, 20-60s walk + sit, 60-90s read the mission card aloud. Add MP3 from ElevenLabs using `demo-narration.txt` as voiceover if wind noise is bad.
4. Note: park name, time, sun_score, 1 honest line for the DEV post Outside test section.
5. Upload video unlisted to YouTube, paste link in DEV post Demo section.
